## Install

```bash
npm install zest-ui
```

```tsx
import 'zest-ui/tokens.css';
import { ZestProvider, Button } from 'zest-ui';

export function App() {
  return (
    <ZestProvider>
      <Button>Get started</Button>
    </ZestProvider>
  );
}
```

## Principles

- **Tokens first** — every color, radius, height, and shadow comes from `--zest-*`
  design tokens. Retheme the whole system by overriding a handful of aliases.
- **One highlight per row** — active and hovered rows carry a single tinted
  background; icons only change color. No nested highlight boxes.
- **Base UI underneath** — popups, fields, and selection widgets ride on
  Base UI primitives for keyboard navigation and accessible semantics.
- **Light & dark** — flip the toolbar's <em>Mode</em> control; every component
  reads the same semantic tokens in both themes.

## Finding your way

| Section | What lives there |
|---|---|
| **Overview** | A composed “Members Page” showing components working together |
| **Foundation** | Design tokens, typography scale, and the icon set |
| **Layout** | Box, Stack, Flex, Grid, Container, Paper, AspectRatio, ScrollArea |
| **Actions** | Button, IconButton, ButtonGroup, Toggle, Link |
| **Forms** | Fields, selection controls, pickers — all Field-aware |
| **Navigation** | Sidebar, AppBar, Tabs, Menu, Command palette, Stepper |
| **Overlays** | Dialog, AlertDialog, Drawer, Popover, Tooltip |
| **Feedback** | Alert, Toast, progress and skeleton loaders |
| **Data Display** | Table, DataGrid, Card, Avatar, Badge, Chip, lists |
| **Patterns** | Ready-made page patterns: SearchToolbar, FormSection, DetailHeader |

Every component page includes a **Docs** tab with a live props table generated
from its TypeScript types.
